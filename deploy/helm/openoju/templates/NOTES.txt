Próximos passos
---------------
1. Confirme o DNS e o TLS do host público.
2. Faça o setup inicial (token único no Secret):

   TOKEN=$(kubectl -n {{ .Release.Namespace }} get secret {{ include "openoju.secretName" . }} \
     -o jsonpath='{.data.OJU_SETUP_TOKEN}' | base64 -d)

   curl -sS -X POST {{ .Values.config.OJU_PUBLIC_BASE_URL }}/api/v1/auth/setup \
     -H 'Content-Type: application/json' \
     -d "{\"token\":\"$TOKEN\",\"organization_name\":\"Minha org\",
          \"organization_slug\":\"minha-org\",\"owner_email\":\"voce@example.com\",
          \"owner_password\":\"...\",\"owner_display_name\":\"Owner\"}"

3. Verifique a saúde e o fluxo de upload:

   kubectl -n {{ .Release.Namespace }} run openoju-test --rm -it --restart=Never \
     --image={{ include "openoju.image" . }} -- \
     curl -sS http://{{ include "openoju.fullname" . }}:{{ .Values.service.port }}/api/health
