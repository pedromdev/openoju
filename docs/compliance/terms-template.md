> Publicar por organização. Revisão jurídica obrigatória.

## 1. Aceitação

O acesso ao sistema é restrito a usuários autorizados pela organização. Ao
utilizar o serviço, o usuário declara ciência destes termos e da política de
privacidade.

## 2. Uso permitido

- Monitoramento de segurança patrimonial.
- Revisão de eventos e exportação para fins legítimos.
- Envio de vídeos por API key apenas para a organização da credencial.

## 3. Condutas proibidas

- Acessar dados de outra organização.
- Compartilhar credenciais, API keys ou sessões.
- Usar o sistema para vigilância ilegal, assédio ou discriminação.
- Tentar contornar controles de acesso ou realizar engenharia reversa maliciosa.
- Inserir conteúdo ilícito.

## 4. Contas e credenciais

O usuário é responsável por manter senha e dispositivos seguros. A organização
pode revogar acessos a qualquer momento. API keys devem ser rotacionadas
periodicamente.

salvo acordo específico.

## 6. Propriedade intelectual

O software é licenciado sob Apache-2.0. Os dados pertencem à organização
controladora.

Na extensão permitida pela lei, o fornecedor não responde por danos indiretos
decorrentes de uso indevido, credenciais comprometidas ou falha de terceiros.

O acesso pode ser suspenso por violação destes termos, risco de segurança ou
determinação legal.
